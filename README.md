# lucastrinh.com — Personal website

Original static website inspired by the dark editorial, monospace, interactive-card aesthetic of the reference site. No source code or copyrighted media copied from the reference.

## Files
- `index.html` — page content
- `styles.css` — layout, colours, responsive design and illustrations
- `script.js` — interactive reflections

## Publish via GitHub + Cloudflare Pages
1. In your GitHub repository, replace `index.html`, `styles.css`, and `script.js` with the files from this folder (do not upload only the ZIP).
2. Commit changes to `main`.
3. Your connected Cloudflare Pages project should deploy automatically. Check Workers & Pages > your project > Deployments.
4. Hard-refresh the website if you see an older version.

No build command is required. The output directory is the repository root (`/`).

## Personalisation
- Replace the text in `index.html` with your own words.
- Change colours in the `:root` section of `styles.css`.
- The Spotify buttons link to the playlist you provided; there is no embedded audio player and no autoplay.
- The 'Professional' label is decorative and intentionally not a clickable navigation link until you decide to build that section.
- There are no invented contact details, photos, achievements or personal memories.
